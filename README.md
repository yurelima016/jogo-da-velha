Um jogo da velha moderno, responsivo e interativo desenvolvido com HTML5, CSS3 e JavaScript puro (Vanilla JS). Este projeto apresenta um design visualmente atraente com tema escuro, cores neon e animações fluidas.

## ✨ Funcionalidades

- **Interface Moderna:** Design limpo com tema escuro e detalhes em neon (vermelho para X, azul para O).
- **Totalmente Responsivo:** Adapta-se perfeitamente a qualquer tamanho de tela, de celulares a monitores desktop.
- **Feedback Visual:**
  - Indicador de turno ("Vez do jogador X/O") que desaparece automaticamente após alguns segundos para manter a tela limpa.
  - Barra de progresso visual no indicador de turno.
  - Efeitos de luz ambiente nos cantos da tela.
- **Pop-up de Resultado:** Mensagem clara de vitória ou empate ao final da partida.
- **Reinício Automático:** O jogo é reiniciado automaticamente ao fechar o pop-up de resultado.

## 🚀 Tecnologias Utilizadas

- **HTML5:** Estrutura semântica da página.
- **CSS3:** Estilização avançada com Flexbox, CSS Grid, variáveis CSS (`:root`), animações (`@keyframes`) e design responsivo (`@media queries`).
- **JavaScript (ES6+):** Lógica do jogo, manipulação do DOM e controle de estado.
- **Bootstrap Icons:** Ícones vetoriais para os símbolos X, O e fechar.
- **Google Fonts:** Fonte "Fugaz One" para um visual tipográfico único.

## 🔧 Como Executar

Este é um projeto estático, então é muito simples de rodar:

1. Clone este repositório:
   ```bash
   git clone [https://github.com/seu-usuario/seu-repositorio.git](https://github.com/seu-usuario/seu-repositorio.git)
   ```
2. Abra o arquivo index.html diretamente no seu navegador preferido (Chrome, Firefox, Edge, etc.).

## 🕹️ Como Jogar

1. O jogo começa sempre com o **Jogador X**.
2. Clique em qualquer quadrado vazio no tabuleiro para fazer sua jogada.
3. O turno passará automaticamente para o próximo jogador.
4. O primeiro a conseguir uma linha, coluna ou diagonal com 3 símbolos iguais vence.
5. Se todas as casas forem preenchidas sem um vencedor, o jogo termina em empate.
